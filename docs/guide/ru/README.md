# Руководство пользователя Shell++

[English](../README.md) | Русский

Shell++ — SSH-клиент, который хранит ваши данные на ваших же устройствах:
хосты, ключи, пароли и сниппеты лежат в зашифрованном хранилище (vault), а
синхронизация между устройствами идёт через сервер, который вы размещаете
сами, если она вам вообще нужна.

1. [Первый запуск и мастер-пароль](01-first-run.md): создание хранилища,
   разблокировка и блокировка, забытый пароль.
2. [Хосты, группы и теги](02-hosts.md): добавление хостов, групп и тегов,
   быстрое подключение, импорт из `~/.ssh/config`, PuTTY и CSV, известные
   хосты.
3. [Ключи, Keychain и экспорт на хост](03-keys.md): создание и импорт
   ключей, ключи безопасности FIDO2, установка ключа на серверы, проброс
   агента.
4. [Терминал](04-terminal.md): вкладки, панели, рабочие пространства,
   одновременный ввод, боковая панель терминала, сочетания клавиш.
5. [SFTP, проброс портов и сниппеты](05-sftp-forwarding-snippets.md),
   а также журнал подключений.
6. [Синхронизация между устройствами](06-sync.md): установка сервера у себя
   дома, три способа доступа к нему, второе устройство, Recently deleted,
   резервные копии.
7. [Экспорт данных и переход с другого клиента](07-export-and-migration.md).

## Условные обозначения

- Интерфейс на английском; руководство приводит его надписи **жирным**.
- Сочетания клавиш указаны для Windows. На Mac используются Cmd и
  некоторые другие клавиши; Settings > **Shortcuts** показывает сочетания
  приложения и терминала, и там же их можно изменить.
- «Меню приложения» — кнопка с тремя полосками слева в верхней панели;
  окно Settings (настройки) открывается по Ctrl+, или из меню приложения.
- На скриншотах демонстрационные данные (вымышленные хосты и ключи).

## Как получить Shell++

Shell++ 1.0 — для Windows и Linux; релизы лежат на странице
[Releases](https://github.com/proxyboy228/shellpp/releases) проекта, у каждого
есть `SHA256SUMS` и подпись minisign для каждого файла (как проверить
скачанное, показывает [docs/release.md](../../release.md#checking-a-download)).

- **Windows:** `shellpp-<version>-windows-x64.zip` — переносимое приложение:
  распакуйте его и запустите `shellpp.exe`, ничего устанавливать не нужно.
  Исполняемый файл не подписан сертификатом, поэтому при первом запуске
  SmartScreen может предупредить: **Подробнее**, затем **Выполнить в любом
  случае**.
- **Linux:** в `shellpp-<version>-linux-x64.tar.gz` — программа, пункт меню
  и его значок; [README](../../../README.ru.md#linux) перечисляет, что нужно
  (glibc 2.35 или новее, драйвер Vulkan или OpenGL через EGL, поставщик
  Secret Service для
  «Remember on this device»), и три команды установки для своего
  пользователя. Linux проверен в контейнерах, на настоящем рабочем столе —
  ещё нет.
- **Обновления:** Help > **Check for Updates** сообщает о новом релизе
  и открывает его страницу; она никогда ничего не скачивает и не
  устанавливает. Кандидат в релиз (`1.0.0-rc.1`) не видит обновлений, пока
  не опубликован 1.0.0.

Можно и собрать приложение из исходного кода, как описано в
[README](../../../README.ru.md#сборка-из-исходного-кода).
