# Third-party notices of the sync server

This file lists the third-party software in the Shell++ sync server's binary
(`shellpp-server`) and in its Docker image, together with its license. The
server itself is licensed under the GNU Affero General Public License v3.0
only ([LICENSE](LICENSE)). The release archive
`shellpp-server-<version>-linux-x64.tar.gz` ships this file next to the
binary, and the image keeps it in `/usr/share/doc/shellpp-server/` with the
server's license.

The licenses of the Rust crates are checked by `cargo deny` with
`server/deny.toml` (the local criterion, `scripts\verify.ps1`, and CI);
`node scripts/rust-notices.mjs` fails when the table below no longer matches
the crates of the binary, and `node scripts/rust-notices.mjs --write`
regenerates it.

## Rust crates

Crates linked into the static binary (`x86_64-unknown-linux-musl` and
`aarch64-unknown-linux-musl`, as `server/Dockerfile` builds it): the normal
dependencies of `shellpp-server`, without procedural macros, which run only
in the compiler, and without the project's own `shellpp-sync-api`. The table
is generated by `scripts/rust-notices.mjs`; edit the dependency, not the
table. "A OR B" means the crate is available under either license.

## The Docker image

The image is based on Alpine Linux 3.22 (`alpine:3.22`). Its packages (musl,
BusyBox, apk-tools and the others) keep their own licenses, which the image's
package database lists (`/lib/apk/db/installed`, the `L:` line of each
package). Shell++ adds only the server binary, its license, this file and an
unprivileged user.
