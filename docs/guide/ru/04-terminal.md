# Терминал: вкладки, панели, рабочие пространства и одновременный ввод

[English](../04-terminal.md) | Русский

Каждая сессия открывается во вкладке верхней панели, рядом с **Vaults** и
**SFTP**. Сочетания клавиш ниже — для Windows (набор "PC"). На Mac
используется набор "Mac" с Cmd, где некоторые клавиши отличаются
(например, Cmd+C и Cmd+V в терминале, Cmd+D для разделения на панели);
Settings > **Shortcuts** показывает их, и там же можно изменить любое из
них.

![Вкладки терминала](../images/terminal-tabs.png)

## Открытие сессии

- **С экрана Hosts**: дважды щёлкните карточку хоста или выделите карточки
  и нажмите Enter (по вкладке на хост). В контекстном меню карточки есть
  **Quick Connect** и **Connect** > **via SSH** / **via Telnet**. Чтобы
  открыть сессию в новом окне, удерживайте Alt при щелчке.
- **Из панели хоста**: кнопка **Connect** внизу.
- **Быстрое подключение**: введите адрес в строку поиска на экране Hosts и
  нажмите Enter: `host`, `user@host`, `user@host:port`, `host:port` или
  даже `ssh user@host -p 2222` (одно слово считается адресом, только если
  в нём есть точка, если это IP-адрес или `localhost`). После успешного
  быстрого подключения Shell++ предлагает сохранить хост.
- **Страница новой вкладки**: **+** в верхней панели или Ctrl+T
  (Ctrl+Shift+T внутри терминала). Её поиск находит хосты, открытые
  вкладки и рабочие пространства, а под ним — ваши **Recent connections**
  (недавние подключения). Выбранный хост открывается в этой же вкладке.
- **Поиск отовсюду**: Ctrl+K (Ctrl+Shift+K внутри терминала) открывает тот
  же поиск поверх текущего экрана; хост открывается в новой вкладке, а
  открытая вкладка выводится на передний план.

![Страница новой вкладки](../images/new-tab.png)

**Restore** на странице новой вкладки снова открывает окна, вкладки и
панели предыдущего запуска (один раз за запуск).

### Локальный терминал, Telnet и последовательный порт

- **Локальный терминал**: кнопка **Terminal** на экране Hosts, меню
  приложения > **New Local Terminal** или Ctrl+L (вне терминала).
  Открывается ваша оболочка по умолчанию: PowerShell 7, если он
  установлен, иначе Windows PowerShell. В этой версии нет настройки, чтобы
  выбрать другую оболочку.
- **Telnet**: добавьте хосту блок Telnet (панель хоста > **Add Telnet**),
  затем выберите **Connect** > **via Telnet**. Telnet не шифруется, а вход
  выполняется интерактивно.
- **Последовательный порт**: меню приложения > **New Serial Connection**,
  кнопка **Serial** на экране Hosts или Ctrl+Alt+S (вне терминала).
  Выберите порт (например, COM3), скорость и параметры линии; они
  запоминаются на этом устройстве.

### Подключение, ключи хостов и пароли

Во время подключения вкладка показывает этапы (разрешение имени,
подключение, проверка ключа хоста, аутентификация, открытие сессии) и
кнопку **Cancel**. При неудаче вы увидите причину и кнопку **Retry**.

При первом подключении к серверу Shell++ показывает отпечаток его ключа
хоста:

- **Accept and save**: доверять ключу и запомнить его (Known Hosts);
- **Connect once**: доверять ему только для этого подключения;
- **Cancel**.

Если сохранённый ключ сервера изменился, Shell++ останавливается с
сообщением "The host key has changed". Это может значить, что сервер
переустановили или что кто-то перехватывает соединение: прежде чем
выбрать **Replace saved key**, уточните у администратора сервера. С
отозванным ключом подключение не выполняется никогда.

![Первое подключение к серверу](../images/terminal-tofu.png)

Запросы пароля, парольной фразы и keyboard-interactive появляются поверх
вкладки, которой они нужны. Можно отметить **Save the password in the
encrypted storage** (для сохранённых хостов) или **Save the passphrase in
the encrypted storage**; для файлов ключей из `~/.ssh` вместо этого можно
выбрать **Remember until Shell++ locks or exits**. Без отметки ничего не
сохраняется.

### Когда соединение обрывается

Вывод остаётся на экране, приглушённый, с надписью **Connection lost** и
причиной. Если **Autoreconnect** включён (по умолчанию, Settings >
**Terminal**), Shell++ пробует снова через 1, 2, 4, 8, 16 и 32 секунды,
затем каждую минуту; в это время доступны **Reconnect now** и **Cancel**.
Сессия, завершившаяся с кодом выхода 0, закрывает свою вкладку; при другом
коде выхода показывается "Session ended with code N" и кнопка
**Reconnect**.

## Вкладки

- **Переключение**: щёлкните вкладку; Ctrl+1 — Vaults, Ctrl+2 — SFTP, с
  Ctrl+3 по Ctrl+9 — вкладки сессий; Alt+→ и Alt+← переходят к следующей и
  предыдущей вкладке.
- **Закрытие**: × на вкладке или Ctrl+Shift+W (на вкладке с панелями
  закрывается активная панель).
- Точка на вкладке показывает состояние: жёлтая, пока идёт подключение,
  зелёная, когда подключено, красная, когда соединение оборвалось.

Щёлкните вкладку правой кнопкой, чтобы открыть её меню:

![Меню вкладки](../images/tab-menu.png)

- **Duplicate** открывает ещё одну сессию к тому же хосту (или ту же
  оболочку) в новой вкладке; **Duplicate in a New Window** — в новом окне.
- **Rename** даёт вкладке ваше собственное имя. Enter сохраняет, Esc
  отменяет; пустое имя возвращает имя хоста.
- **Split Horizontally** и **Split Vertically** (ниже).
- **Broadcast Input** (ниже).
- **Close** закрывает вкладку со всеми её панелями.

## Разделение на панели

Разделите вкладку на панели, чтобы видеть несколько сессий сразу:

- Ctrl+Shift+D: новая панель справа;
- Ctrl+Shift+E: новая панель снизу;
- или **Split Vertically** / **Split Horizontally** в меню вкладки.

Новая панель спрашивает, какой хост открыть. Первая строка — хост панели,
которую вы разделили, затем идут недавние подключения; начните вводить,
чтобы искать. Enter подключает, Esc снова закрывает новую панель.

![Вкладка с четырьмя панелями](../images/terminal-splits.png)

- Переходите между панелями щелчком или Ctrl+Alt+←/→/↑/↓. У активной
  панели вдоль верхнего края идёт линия акцентного цвета.
- Перетащите линию между двумя панелями, чтобы изменить их размер.
- Ctrl+Shift+W закрывает активную панель; с последней панелью закрывается
  и вкладка.
- Во вкладке может быть до 16 панелей.

## Рабочие пространства

Рабочее пространство (workspace) — сохранённый набор вкладок и панелей,
который открывается за один раз.

- **Сохранить текущее окно**: на странице новой вкладки нажмите **Create a
  workspace** и задайте имя. Сохраняются вкладки сохранённых хостов и
  локальных терминалов, с их панелями и именами. Вкладка с сессией
  быстрого подключения не сохраняется, как и сессии последовательного
  порта.
- **Добавить хосты в рабочее пространство**: на экране Hosts щёлкните
  хосты правой кнопкой > **Add to Workspace** > рабочее пространство (или
  **New Workspace**). Каждый хост становится отдельной вкладкой.
- **Открыть**: блок **Workspaces** на странице новой вкладки или поиск
  рабочего пространства через Ctrl+K. Его вкладки открываются в текущем
  окне и подключаются.
- **Переименовать или удалить**: карандаш и × рядом с кнопкой рабочего
  пространства. После удаления на несколько секунд доступна **Undo**;
  удаление никогда не затрагивает ваши хосты.

Если хостов рабочего пространства больше нет, оно показывает "N hosts not
found", а при открытии пропускает их.

## Одновременный ввод

Одновременный ввод (Broadcast input) отправляет набираемое сразу в
несколько сессий, например чтобы выполнить одну команду на нескольких
серверах.

- **Ctrl+Shift+B** включает его для панелей текущей вкладки.
- **Broadcast Input** в меню вкладки позволяет отметить несколько вкладок:
  ввод в подключённой панели любой отмеченной вкладки уходит в подключённые
  панели всех отмеченных. Нужно хотя бы две подключённые панели.

![Одновременный ввод в несколько вкладок](../images/broadcast-marks.png)

Пока режим включён, у вкладок, участвующих в нём, жёлтый значок вышки, а у
панелей, которые получают ввод, жёлтая рамка. Вставка нескольких строк
всегда сначала спрашивает подтверждение и говорит, сколько других панелей
их получат. Пока панель ждёт пароль, ввод не дублируется. Повторное
Ctrl+Shift+B или **Stop Broadcast Input** в меню вкладки выключает режим.

## Боковая панель терминала

Кнопка **Terminal sidebar** в верхней панели (на вкладках сессий)
открывает рядом с терминалом панель с четырьмя страницами:

- **Tools**: поиск в выводе и истории прокрутки (открывается по
  Ctrl+Shift+F). Enter и Shift+Enter переходят к следующему и предыдущему
  совпадению. Здесь же и в Settings > **Terminal** параметр
  **Autocomplete (beta)** (автодополнение) можно поставить в **This
  host's history**: пока вы печатаете, после курсора бледно появляется
  продолжение команды, которую вы уже выполняли на этом хосте, а Tab или →
  принимают его. Оно работает в оболочках, которые отмечают своё
  приглашение (bash 5.1 и новее, zsh, fish), на сохранённых хостах, никогда
  — при запросе пароля и в полноэкранных программах, и никогда не
  предлагает команды, похожие на секреты.
- **Snippets**: щёлкните сниппет, чтобы вставить его без выполнения, или
  нажмите его кнопку запуска, чтобы вставить его и нажать Enter.
  Переменные вроде `{{name}}` запрашиваются заранее
  ([Сниппеты](05-sftp-forwarding-snippets.md#сниппеты)).
- **History**: команды, которые вы выполняли на этом хосте (только для
  сохранённых хостов). Щёлкните команду, чтобы вставить её. **Clear
  history** и кнопка удаления в каждой строке удаляют команды. Историю
  можно выключить в Settings > **Terminal** > **Record command history**.
- **Appearance**: темы терминала и страница **Font** (шрифт, размер
  текста, межстрочный интервал). Тема, выбранная здесь, применяется к этой
  сессии и сохраняется для хоста.

![Страница Snippets в боковой панели терминала](../images/sidebar-snippets.png)

## Копирование, вставка и мышь

- Ctrl+Shift+C копирует, Ctrl+Shift+V вставляет, Ctrl+Shift+A выделяет
  всё.
- Выделяйте перетаскиванием; двойной щелчок выделяет слово, тройной —
  строку.
- **Правый щелчок вставляет.** Если включено **Copy on select**
  (Settings > **Terminal**), выделенное копируется, как только вы
  отпустите кнопку мыши.
- Вставка текста с переводом строки сначала спрашивает подтверждение
  ("Paste several lines?" или "Paste and run?" для одной строки, которая
  заканчивается переводом строки) и показывает, что будет вставлено, чтобы
  команда не выполнилась случайно.
- Когда полноэкранная программа вроде `htop` или `mc` использует мышь, для
  выделения или вставки удерживайте Shift.
- История прокрутки хранит 10 000 строк. Shift+PageUp и Shift+PageDown
  прокручивают на страницу; Shift+Home и Shift+End переходят в начало и в
  конец.

## Settings > Terminal

Основные параметры: **Autoreconnect**, **Record command history**, **Copy
on select**, **Bell sound**, **Keyword highlighting** (ошибки,
предупреждения, адреса и ваши собственные регулярные выражения выделяются
цветом), тип терминала (по умолчанию `xterm-256color`), шрифт, тема
терминала по умолчанию и интервал **Keepalive** (по умолчанию 30 секунд;
0 выключает его).

**Масштаб**: View > **Zoom In** / **Zoom Out** / **Actual Size** в меню
приложения или Ctrl+=, Ctrl+- и Ctrl+0 вне терминала масштабируют весь
интерфейс от 80 % до 200 %. Размер текста самого терминала задаётся
отдельно, в настройках шрифта.

**Флаги в Windows** показываются двумя буквами (🇺🇦 — как `UA`): в Windows
нет глифов флагов, и Windows Terminal показывает их так же. Это известное
ограничение (`docs/compatibility.md`).

## Сочетания клавиш

Settings > **Shortcuts** показывает все сочетания. Щёлкните сочетание
действия и нажмите новое (с Ctrl, Alt или F-клавишей); × оставляет
действие без сочетания; **Reset all** возвращает значения по умолчанию.
Пока фокус в терминале, сочетания без Shift (например, Ctrl+L или Ctrl+K)
уходят программе в терминале.

| Действие | Клавиши (Windows) |
|---|---|
| Новая вкладка | Ctrl+T, Ctrl+Shift+T |
| Поиск хостов и вкладок | Ctrl+K, Ctrl+Shift+K |
| Закрыть вкладку или панель | Ctrl+Shift+W |
| Следующая / предыдущая вкладка | Alt+→ / Alt+← |
| Vaults, SFTP, вкладки 3–9 | Ctrl+1, Ctrl+2, Ctrl+3–9 |
| Новый локальный терминал | Ctrl+L |
| Новое подключение к последовательному порту | Ctrl+Alt+S |
| Заблокировать Shell++ | Ctrl+Shift+L |
| Настройки | Ctrl+, |
| Увеличить / уменьшить / исходный масштаб | Ctrl+= / Ctrl+- / Ctrl+0 |
| Копировать / вставить / выделить всё | Ctrl+Shift+C / Ctrl+Shift+V / Ctrl+Shift+A |
| Разделить вправо / вниз | Ctrl+Shift+D / Ctrl+Shift+E |
| Перейти к панели слева / справа / сверху / снизу | Ctrl+Alt+← / → / ↑ / ↓ |
| Поиск в терминале | Ctrl+Shift+F |
| Включить или выключить одновременный ввод | Ctrl+Shift+B |
