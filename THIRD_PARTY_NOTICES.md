# Third-party notices

This file lists third-party software, fonts and other material that is
included in or distributed with this project, together with its license.

Rules (see `SPEC.md`, section "Clean room", and `docs/architecture.md`,
section 8):

- Only permissive licenses are allowed: MIT, Apache-2.0, BSD-2-Clause,
  BSD-3-Clause, ISC, MPL-2.0, Zlib, BSL-1.0, Unicode-3.0, CC0-1.0, Unlicense,
  0BSD, CDLA-Permissive-2.0 and public domain (SQLite); OFL-1.1 for fonts.
  GPL and AGPL code is forbidden in the client distribution (see
  `docs/decisions.md`, decision 4).
- Development-only packages that are never shipped may also use BlueOak-1.0.0
  and CC-BY-4.0. They are not listed here.
- Check the license before adding a dependency and add it here in the same
  pull request. CI enforces this:
  - `cargo deny check` (`deny.toml`) checks the licenses, bans, advisories and
    sources of every Rust crate of the client workspace (the local criterion,
    `scripts\verify.ps1`, runs it too);
  - `node scripts/rust-notices.mjs` fails when the Rust table below no longer
    matches the crates that ship in the desktop binary
    (`node scripts/rust-notices.mjs --write` regenerates it).
- Where a license requires it (for example Apache-2.0 `NOTICE` files or the
  OFL), the full license text ships with the distributed application.

## The Android prototype (apps/android)

The debug APK of the Android prototype (run 13; not distributed) ships the
Rust crates of the shared core listed above that its library links, plus
the `jni` crate and its dependencies (MIT OR Apache-2.0, checked by
`cargo deny` with the client workspace), JetBrains Mono Regular with its
license (`apps/android/app/src/main/assets/fonts/OFL.txt`), and the Kotlin
standard library (Apache-2.0, <https://github.com/JetBrains/kotlin>). Its
tests use JUnit 4 (EPL-1.0) and AndroidX Test (Apache-2.0), which never
ship in the app. The full table of the Android app comes with its first
release.
