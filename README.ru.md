# Shell++

[English](README.md) | Русский

Shell++ — self-hosted SSH-клиент, построенный по принципу local-first. В первую очередь он разрабатывается для настольных платформ (Windows, macOS, Linux), мобильные версии появятся позже. В нём есть хосты и группы, связка ключей для SSH-ключей и учётных данных, терминал с вкладками и разделением на панели, сниппеты, SFTP и проброс портов. Синхронизация между устройствами необязательна, защищена сквозным шифрованием и работает через сервер, который вы размещаете сами.

## Принципы

1. **Local-first.** Приложение полностью работает офлайн, без учётной записи и без сервера. Синхронизация необязательна.
2. **Никаких проверок лицензии. Никакой телеметрии.** Нет проверок лицензии или подписки, пробных периодов, тарифов, телеметрии, обращений «домой» и удалённого отключения функций.
3. **Ваши данные всегда остаются читаемыми и доступными для экспорта.** Если доступ к общему хранилищу отозван, учётная запись удалена, вы вышли из неё или сервер недоступен, локальная копия остаётся доступной, и её можно экспортировать. Отзыв доступа лишь прекращает дальнейшую синхронизацию. Он никогда не удаляет и не блокирует удалённо уже полученные данные.
4. **Экспорт в открытые форматы.** В любой момент можно экспортировать данные в JSON (документированная схема, открытый или зашифрованный), `~/.ssh/config`, ключи в формате OpenSSH и `known_hosts`.
5. **Синхронизация с нулевым разглашением.** Сервер синхронизации хранит только зашифрованные блоки данных и метаданные синхронизации. Ключи шифрования никогда не покидают клиент в открытом виде.

## Статус

Shell++ находится на ранней стадии разработки. Готовы спецификации, дизайн-документы этапа 0, дизайн-токены и базовые компоненты интерфейса; самого приложения ещё нет.

- Приложением пока нельзя пользоваться, устанавливать нечего.
- Спецификации, форматы данных и интерфейсы могут меняться без обратной совместимости.

## Планируемый стек

- Настольное приложение: Tauri 2 (ядро на Rust) с React и TypeScript.
- Терминал: xterm.js.
- SSH: russh.
- Локальное хранилище: SQLite с шифрованием на уровне записей.
- Сервер синхронизации: Rust (axum) с PostgreSQL или SQLite, поставляется как Docker-образ.
